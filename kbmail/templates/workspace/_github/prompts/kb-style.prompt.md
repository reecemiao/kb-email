Run `kbmail style` and read `work/style/SAMPLES.md`. Write `wiki/style/writing-style.md` (front matter per
`wiki/SCHEMA.md`, type `style`) describing how the user writes, with short real examples:
languages used and when (e.g. Japanese to internal, English to vendors), greetings and closings per
audience (internal/external, senior/peer), keigo level, sentence length, use of bullets, how requests and
deadlines are phrased, how they say no, sign-off and signature, typical subject line patterns.
Keep it practical: a drafting checklist at the end. Update `wiki/index.md` and `wiki/log.md`.
